# Contributing

Contributions should preserve the project's research-integrity rules:

1. Keep physical source groups intact across data splits.
2. Do not tune thresholds or features on a final test partition.
3. Record random seeds, configuration and environment information.
4. Preserve negative results.
5. Do not describe XAI outputs as causal explanations.
6. Do not combine heterogeneous trust signals into a scalar score without new predeclared validation.
7. Never commit raw datasets, credentials or private keys.
8. Every performance claim should point to a reproducible experiment artifact.
