# Negative findings

TrustTwin treats negative results as evidence.

- Per-trace exploratory RPM estimation did not outperform nominal-RPM normalisation.
- Temperature scaling did not transfer safely across unseen-speed shift.
- Naive scalar/combined trust models were not supported.
- Generic and speed-conditioned explanation prototype gates failed.
- Global predictive OOD thresholds failed under simultaneous operating shift.
- One-phase current did not improve vibration through unsynchronised equal late fusion.
- In-domain temperature scaling became degenerate.
- The independent UCI valve classifier remained weak; conformal routed nearly all cases to review.

These findings constrain the final architecture and remain visible by design.
