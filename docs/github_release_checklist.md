# GitHub release checklist

**Repository:** `TrustTwin-AI`

Recommended description:

> Trust-aware fault diagnosis for industrial digital twins: domain support, sensor health, OOD evidence, conformal abstention and human review.

Recommended topics:

`digital-twin`, `predictive-maintenance`, `fault-diagnosis`, `trustworthy-ai`, `conformal-prediction`, `uncertainty-quantification`, `xai`, `condition-monitoring`, `industrial-ai`, `research-software`

Before tagged release:

- Confirm CI passes.
- Review author/contact metadata.
- Confirm no raw datasets or secrets are present.
- Add paper/preprint DOI to `CITATION.cff` when available.
- Optionally create a Zenodo-linked release for a software DOI.
- Tag `v0.1.0`.
