# Limitations

1. Most diagnostic development used NLN-EMP Motor-2.
2. Later Motor-2 experiments are development evidence, not untouched final external validation.
3. Fault/source-condition generalisation is family-dependent.
4. Some electrical fault conditions have equipment-identity confounding concerns.
5. Synthetic corruptions do not cover all industrial sensor failures.
6. Split-conformal coverage depends on exchangeability and is not guaranteed under arbitrary shift.
7. UCI Phase 8A retrains on a different dataset; it is workflow replication, not direct classifier transfer.
8. TrustTwin is not safety-certified and does not autonomously execute maintenance.
